# Exercises

Practice problems for each level, authored in Milestone 8. Each exercise set will include
estimation drills, design prompts, and "what would break" questions keyed to that level's
chapters.

## Planned (M8)
- `00-prerequisites/` — complexity & networking drills
- `01-foundations/` — capacity-estimation problems
- `02-core-components/` — component-selection scenarios
- `03-data-storage/` — schema/sharding/replication exercises
- `04-distributed-systems/` — consistency & consensus reasoning
- `05-architecture-patterns/` — pattern-choice & "when not to use" drills
- `06-reliability/` — failure-injection & SLO-design problems
- `07-security/` — threat-modeling (STRIDE) exercises
- `08-observability/` — alert & dashboard design problems
- `09-cloud-platform/` — deployment & autoscaling scenarios
- `10-extreme-scale/` — multi-region & billion-user design prompts
