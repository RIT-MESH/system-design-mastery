# Level 1 — Foundations — Exercises

Practice problems keyed to the [01-foundations](../../docs/01-foundations/README.md) level.

## Estimation & reasoning drills

- 1. Take the paste-service estimate and re-estimate at 100x scale. What becomes the binding resource?
- 2. A system must be 'reliable' — restate that as a measurable SLO with an SLI and error budget.
- 3. Identify the read:write ratio for a logging platform and name the storage class it implies.

## Design prompts

- 4. Project 8k writes/s next year; one node handles 5k. When do you shard, and how would you size the buffer?
- 5. Give one example where availability and durability pull in opposite directions.

## What would break? / when NOT to use

- 6. Why does p99 matter more than average for a user-facing API?

> Answers are intentionally open-ended; discuss trade-offs and constraints. See the matching chapters and the [interview framework](../../interview-framework/README.md).
