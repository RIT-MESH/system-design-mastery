# AI Simulations

Each subdirectory corresponds to a simulation topic. The runnable Python tools are in [`examples/ai/`](../../examples/ai/).

| Subdirectory | Tool | Description |
|--------------|------|-------------|
| `chunking/` | [`chunking_simulator.py`](../../examples/ai/chunking_simulator.py) | Chunk-size and overlap trade-off simulator |
| `semantic-cache/` | [Semantic Caching chapter](../../docs/ai-systems/14-semantic-caching.md) | Embedding-based cache lookup and safety risks |
| `model-routing/` | [`model_routing_simulator.py`](../../examples/ai/model_routing_simulator.py) | Multi-model routing by task type and cost |
| `hybrid-search/` | [Hybrid Search chapter](../../docs/ai-systems/05-hybrid-search-reranking.md) | Keyword+vector fusion and reranking |
| `agent-workflows/` | [Agentic Systems chapter](../../docs/ai-systems/08-agentic-systems.md) | ReAct, planner-executor, multi-agent coordination |
